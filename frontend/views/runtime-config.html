What is validation?

Validation checks whether a config value matches server rules (integer ranges, JSON shape, booleans). It does not let you change those rules in the UI. Use Validate to test your draft. Use Rule Catalog to browse allowed keys and examples. To add or change rules, update backend code in backend/app/routers/runtime_config.py and ship a backend release.

Rule Catalog Read-only

Backend-defined constraints for supported runtime keys. Platform Admins can browse and test rules; Super Admins can add or update catalog entries. Expand any Example row to view the full JSON or value, then use actions to load or test it.

How do I add or change a validation rule?

Super Admins can use Add Rule or Edit in the catalog table. Built-in rules can be updated but not deleted. Custom rules can be removed when no longer needed. Changes apply immediately to validate and save flows.
