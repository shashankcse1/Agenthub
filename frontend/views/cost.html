Spend governance sequence

1. Configure pricing Set model token rates, cloud multipliers, and provider discounts in runtime config.
2. Monitor telemetry Review hourly and daily spend plus gateway analytics for model and endpoint trends.
3. Enforce budgets Create budget policies (user/team/group aliases, session caps, RPM/TPM), evaluate limits, and review hierarchy rollups.
4. Investigate anomalies Review soft/hard scope alerts, explain top contributors, then drill into session and agent cost events.

    Budget Policies

    Spend/utilization on the table uses membership rollup for team/group and treats user/actor/owner as interchangeable person scopes. Session budget and iteration caps are enforced on gateway inference when session_id is present. RPM/TPM bind to the policy scope rollup. Decision is derived from current rollup utilization vs soft/hard thresholds.

    User spend uses CostEvent owner_scope (user:{actor}). Helicone user / user_id properties are analytics labels and are not the budget ledger key. Choose budget window mode to align utilization with each policy’s reset window. Hours spend always reflects the trailing hours window for dual compare against budget-window spend.
