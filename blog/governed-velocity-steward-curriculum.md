# Agency Contract Steward — Training Curriculum

**Role:** Contract Steward (app owner or delegate who files and maintains Agency Contracts)  
**Outcome:** Steward can complete a Contract, pass Definition of Done, and run a revoke/export awareness drill  
**Length:** 4 hours (or 2 × 2 hours) + assessed workshop artifact

---

## Module 0 — Why this exists (20 min)

- Privilege multiplier  
- Filter Era vs Control Plane Era  
- Outcome integrity vs refusal rate  
- **Assessment:** One-sentence thesis in own words  

## Module 1 — The six clauses (40 min)

Teach each clause with the worked example (`examples/agency-contract-worked-example.md`).  
**Exercise:** Mark which tools you would remove from a bloated draft agent.

## Module 2 — Control plane realities (40 min)

- On-plane vs bypass keys  
- Input/output policies  
- MCP allowlist  
- Dual approval — UI theater vs enforcement  
**Exercise:** Trace one request path on a whiteboard.

## Module 3 — Definition of Done lab (50 min)

Fill DoD for a real or sample agent. Peer review with red pen.  
**Gate:** Steward cannot “pass” with empty blast-radius paragraph.

## Module 4 — Exceptions & ethics of speed (25 min)

- Exception form · ≤ 90 days · auto-disable  
- Why permanent exceptions are how privilege multiplies  
**Exercise:** Rewrite a bad justification into “defer” or “compensate.”

## Module 5 — Prove & respond (45 min)

- Scorecard metrics that matter  
- RT-01 / RT-02 walkthrough  
- Golden-hour: what stewards do first (call revoke, do not “debug the prompt” on S1)  
**Exercise:** Order the first five containment steps.

## Module 6 — Assessment (30 min)

| Artifact | Pass criteria |
|----------|---------------|
| Completed Agency Contract | All six clauses concrete |
| DoD checklist | No critical blanks |
| Blast-radius paragraph | Hijack assumed, honest |
| Oral: revoke + export | Can name runbooks / owners |

**Credential:** “Agency Contract Steward (internal)” — renew yearly or on policy major version.

- Certificate for attendance without artifact  
- Stewards from GTM only with no owner authority
