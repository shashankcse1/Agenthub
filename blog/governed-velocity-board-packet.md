# Board Packet Assembly — Risk Committee

**Meeting purpose:** Adopt or review Governed Velocity  
**Owner:** CISO · **Packet due:** 72 hours before session  
**Page limit:** ≤ 12 pages + appendices optional

---

## Packet order (do not reorder)

| # | Document | Max pages | Source file |
|---|----------|-----------|-------------|
| 0 | Cover / CEO note | 0.5 | `ceo-letter` (board cover note) |
| 1 | Leader’s Brief | 2 | `governed-velocity-leaders-brief.md` |
| 2 | Board one-pager (decision) | 1 | `one-pagers/board.md` |
| 3 | Risk appetite (AI-RISK-001) | 2 | `policy/ai-risk-appetite.md` |
| 4 | Resolution (clean copy) | 2 | `policy/board-resolution.md` |
| 5 | Scorecard snapshot | 1 | from live scorecard / sample format |
| 6 | Leader Readiness Score | 1 | `leader-readiness` (current numbers) |
| 7 | Residual risk (plain language) | 0.5 | write for this meeting |
| A | Policy AI-CTRL-001 (appendix) | — | optional full text |
| B | Sample day-90 report (if review meeting) | — | `examples/day90-board-report-sample.md` |

## Facilitator script (20 minutes)

| Min | Move |
|-----|------|
| 0–3 | Era shift in one breath (Filter → Control Plane) |
| 3–8 | Walk six clauses + clocks |
| 8–12 | Appetite refuse list |
| 12–16 | Scorecard / readiness honesty |
| 16–20 | Resolution vote / affirmation · Q&A from `board-qa.md` |

## Pre-wire (48 hours prior)

- Risk chair has seen Leader’s Brief  
- No surprise “we’re L4” language  
- CFO aligned if funding ask attached (investment memo as separate tab)  

## Success criteria

- Resolution adopted **or** explicit deferral with date  
- Appetite refuse list unchanged or tightened (never silently loosened)  
- Next review date on calendar  

## Failure modes

- Feature demo in board room  
- Packet &gt; 12 core pages  
- Metrics guessed live without scorecard
