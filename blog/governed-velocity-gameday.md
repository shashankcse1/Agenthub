# Game Day — Full-Day Governed Velocity Exercise

**Length:** 6.5 hours (+ breaks)  
**Cadence:** Annual (plus quarterly 90m tabletop)  
**Objective:** Prove clocks, clauses, war room, and publish discipline under stress  

---

## Roster

Commander (IR) · OACP · Platform · 2 stewards · Comms · Legal (part-time) · Facilitator · Executive sponsor (checkpoints only)

## Agenda

| Time | Block |
|------|-------|
| 08:30 | Brief: Constitution + desk card + rules of engagement |
| 09:00 | **Track A** — Scorecard & instrumentation hunt (find a real gap) |
| 09:00 | **Track B** — Steward DoD audit on 2 live agents (parallel) |
| 10:15 | Sync: top 3 gaps |
| 10:30 | **Inject series** — Timed tabletop (concealed exfil) expanded |
| 12:00 | Lunch (bridge quiet; no “fixing”) |
| 12:45 | War room replay with sibling-key inject |
| 14:00 | Comms drill: holding statement under 20 minutes |
| 14:45 | Corrective action drafting (decision log IDs) |
| 15:30 | Exec readout (10m): clocks, clauses failed, freeze Y/N |
| 16:00 | Hotwash + AAR skeleton · adjourn |

## Scoring (facilitator)

| Dimension | Pass |
|-----------|------|
| Ledger before chat | Observed in first 10m |
| Revoke command | &lt; 15m from inject-2 |
| No fail-open proposal | Zero suggestions accepted |
| Comms hygiene | No “fully contained” without effective revoke |
| Artifacts | AAR + ≥1 GV-DEC same day |

## Forbidden during Game Day

- Vendor blame as root cause  
- Turning off logging “to go faster”  
- Declaring L4 at the readout  

## Output package (24h)

AAR · decision log entries · readiness score delta · board extract if S1-class lessons
