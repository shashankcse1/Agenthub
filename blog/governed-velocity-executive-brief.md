# Governed Velocity — Executive Brief

**For:** CEO / CISO / Board risk committee  
**Read time:** 3 minutes  
**Decision:** Adopt the Control Plane Era standard for production AI agents

---

## The decision

Leave the **Filter Era** (*hope the model refuses*).  
Enter the **Control Plane Era** (*mediate agency, contain privilege, keep the ledger*).

Approve **governed velocity** as policy:

> Production agents act only under an **Agency Contract** — Identity, Mandate, Toolbox, Escalation, Fence, Ledger.

Replace the review question *“Is the model safe?”* with *“Can we control and prove agency?”*

---

## Why this is a leadership issue (not an IT ticket)

AI is a **privilege multiplier**. Every tool, key, and data path expands what a single hijacked or overeager plan can touch. Chatbots waste time when wrong. Agents create company stories.

Evidence already forces containment:

- Frontier agent stacks remain injectable under indirect prompt injection  
- Dangerous attacks often *look fine* to the user (concealment)  
- Silent egress can bypass chat safety — network controls matter  
- No single filter wins trust, utility, and latency together

Waiting for perfect model safety is a strategy to discover your perimeter in an incident report.

---

## Agency Contract (approve as standard)

| Clause | Non-negotiable meaning |
|--------|-------------------------|
| Identity | Named, scoped, short-lived; NHI hygiene |
| Mandate | Retrieved content = evidence, not instruction |
| Toolbox | Approved tools/MCP only; least agency |
| Escalation | Dual approval for prod / irreversible acts |
| Fence | Egress allowlists, budgets, kill switch |
| Ledger | Exportable allow/deny evidence |

**Defer** any net-new production agent that cannot meet all six clauses.

---

## 90-day prove plan

| Days | Outcome | Owner |
|------|---------|--------|
| 1–30 | AI path inventory; unmanaged keys dead; production inference on control plane; Contract published | Security + Platform |
| 31–60 | Input/output policy on critical routes; tool allowlists; budgets + dual approval live | Platform + App owners |
| 61–90 | Concealment + silent-egress red team; evidence export drill; kill-switch stopwatch; one-page residual risk | CISO → Board |

### Day-90 scoreboard

- % production inference via control plane  
- Dual-approval coverage on prod mutations  
- Egress / passthrough deny rate  
- Median time-to-revoke  
- Evidence export RTO  
- Open red-team findings (honest residual risk)

---

## Board one-liner

We will move fast on AI by putting every production agent under contract — so autonomy scales without turning privilege into an incident. That is governed velocity.

---

## Recommendation

**Approve** Control Plane Era doctrine + Agency Contract + 90-day program.  
**Fund** control-plane coverage before net-new agent sprawl.  
**Review** day-90 scoreboard in committee with residual risk in plain language.
