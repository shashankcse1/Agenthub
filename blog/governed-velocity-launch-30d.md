# Governed Velocity — 30-Day Internal Launch Plan

**Objective:** Make the Control Plane Era the default language and the Agency Contract the default policy — before any product campaign.

---

## Week 0 — Align the room (days −3 to 0)

| Action | Owner | Artifact |
|--------|-------|----------|
| Pre-read to CEO / CISO / CTO | Chief of staff | `executive-brief.md` + role one-pagers |
| Agree vocabulary lock | CISO + Platform | Terms in `README.md` |
| Name day-90 reviewers | CISO | Board / exec sponsor list |
| Ban feature-first decks in launch week | GTM lead | Written norm |

**Exit gate:** Three executives can recite the one-sentence thesis without notes.

---

## Week 1 — Declare the era (days 1–7)

| Day | Action | Artifact |
|-----|--------|----------|
| 1 | All-hands or leadership email | `internal-launch-email.md` |
| 2 | Publish Agency Contract as draft policy | Six clauses + defer rule |
| 3 | Start AI path inventory | Spreadsheet / CMD inventory |
| 4–5 | Kill / schedule kill of unmanaged keys | NHI + key owners |
| 5 | Platform office hours (30 min) | `one-pagers/cto.md` |
| 7 | Week-1 readout: inventory %, keys revoked, questions | 1-page status |

**Exit gate:** Inventory started; unmanaged production keys have owners and dates.

---

## Week 2 — Force the chokepoint (days 8–14)

| Action | Owner |
|--------|-------|
| Default SDKs / configs → control plane for new work | Platform |
| Migrate top 3 production inference paths on-plane | App owners |
| Dual-approval path verified in a non-prod drill | Security eng |
| Shadow-AI amnesty window announced (report without blame) | CISO |

**Exit gate:** At least one tier-1 production path on-plane with audit events visible.

---

## Week 3 — Contract becomes backlog (days 15–21)

| Action | Owner |
|--------|-------|
| Map each contract clause → tickets / controls | Platform + Sec |
| Critical routes: input + output policy draft | Platform |
| MCP allowlist v0 (even if short) | Platform |
| Budget alerts on top spenders | FinOps / Platform |
| Half-day workshop for app owners | See `workshop.md` |

**Exit gate:** Clause→control map published; workshop completed for priority teams.

---

## Week 4 — Prove you can prove (days 22–30)

| Action | Owner |
|--------|-------|
| Evidence export dry run (timed) | Compliance / Sec |
| Kill-switch / revoke drill (timed) | Sec + Platform |
| Red-team scenario selection (concealment + egress) | Sec research |
| Day-30 brief to sponsors | CISO |
| External publish decision (manifesto / LinkedIn) | Comms |

**Exit gate:** Timed revoke + timed evidence export numbers exist. Day-30 brief sent.

---

## Launch anti-patterns (block these)

- Leading with product screenshots before doctrine  
- “AI safety month” with no chokepoint metric  
- Permanent exceptions for “strategic” agents  
- Renaming Filter Era work as Control Plane work without mediation  

---

## Day-30 message to the company

We left the Filter Era on purpose. Production agents now require a contract. The next sixty days constrain and prove. Speed stays; unpriced privilege does not.
