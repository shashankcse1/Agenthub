# OACP Quarterly Business Review (QBR) Template

**Cadence:** Quarterly · **Chair:** Head of AI Control Plane  
**Attendees:** CISO, CTO, FinOps, 2–3 app-owner stewards, optional CRO  
**Length:** 60 minutes · **Rule:** Numbers before narratives

---

## Agenda

| Min | Topic |
|-----|-------|
| 0–5 | Vocabulary refresh (one slide: Contract clauses) |
| 5–20 | Scorecard + SLO burn (coverage, keys, revoke, export, exceptions) |
| 20–30 | Maturity movement (L# last quarter → now) + honesty check |
| 30–40 | Incidents / red team / vendor fails |
| 40–50 | Portfolio: deferred agents, upcoming launches, capacity |
| 50–55 | Investment ask / freeze decisions |
| 55–60 | Actions with owners and dates |
