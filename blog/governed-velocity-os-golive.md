# OS Go-Live Checklist — Declare Governed Velocity Active

**Purpose:** Turn the document kit into a living operating system  
**Accountable:** CISO + CTO  
**Rule:** “We published a folder” ≠ active. This checklist = active.

---

## Gate 0 — Authority (must be Yes)

- [ ] Risk appetite AI-RISK-001 approved by Risk Committee / Board  
- [ ] Board resolution adopted (or delegated committee)  
- [ ] Policy AI-CTRL-001 signed by CISO + CTO (+ CRO if required)  
- [ ] OACP named with freeze authority documented  
- [ ] RACI published internally  

## Gate 1 — Clocks (measured, not aspirational)

- [ ] Scorecard exists with Day-0 baselines (empty cells allowed; green paint forbidden)  
- [ ] Instrumentation events defined; at least infer+tool allow/deny emitting in prod path  
- [ ] First revoke drill completed; median recorded  
- [ ] First evidence export drill completed; RTO recorded  
- [ ] Unmanaged prod key hunt started with owners  

## Gate 2 — Gates that hurt (credibility)

- [ ] Definition of Done required for new prod agents  
- [ ] Day-zero onboarding path published  
- [ ] Exception form live; max 90 days; auto-disable designed or manual runbook owned  
- [ ] At least one launch deferred or exception forced (proves the gate is real)  

## Gate 3 — Rhythm

- [ ] Weekly coverage standup on calendar  
- [ ] First OACP QBR scheduled  
- [ ] Annual calendar accepted by sponsors  
- [ ] Timed tabletop scheduled within 90 days  

## Gate 4 — People

- [ ] Steward curriculum date set for cohort #1  
- [ ] Exam + credential language approved  
- [ ] Truth-to-power scripts shared with CISO/OACP (private)  

## Gate 5 — Voice discipline

- [ ] Leader Readiness Score baselined  
- [ ] External “leader” claims frozen until score ≥ 32  
- [ ] Comms calendar owner named
