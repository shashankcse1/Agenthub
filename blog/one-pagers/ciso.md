# CISO One-Pager — Governed Velocity

**Role:** Own the Agency Contract and day-90 proof  
**Era:** Control Plane — not Filter

---

## Operating standard

Production agents are privileged non-human workers. They do not ship without:

1. **Identity** — scoped, short-lived; NHI hygiene  
2. **Mandate** — input data policy; untrusted context  
3. **Toolbox** — approved MCP/tools; least agency  
4. **Escalation** — dual approval on prod / irreversible  
5. **Fence** — egress/passthrough allowlists, budgets, kill switch  
6. **Ledger** — audit + compliance evidence export

---

## Threat assumptions (design from these)

- Indirect prompt injection will succeed sometimes  
- Concealment: clean user answer ≠ safe outcome  
- Silent egress beats chat DLP alone  
- No single filter wins trust + utility + latency  
- Shadow AI is unpriced privilege until inventoried

**Control objective:** bounded blast radius + outcome integrity + provable decisions — not zero jailbreaks.

---

## 90-day security program

| Phase | You drive |
|-------|-----------|
| See (1–30) | Full AI path inventory; key revocation; force gateway coverage; publish Contract |
| Constrain (31–60) | Critical-route policies; MCP allowlist; budgets; dual-approval enforcement |
| Prove (61–90) | Red-team concealment + silent egress; evidence export RTO; kill-switch stopwatch; residual-risk brief |

---

## Metrics you report upward

| Metric | Signal |
|--------|--------|
| % prod inference on control plane | Chokepoint health |
| Dual-approval coverage (prod mutations) | Escalation health |
| Egress / passthrough deny rate | Fence health |
| Median time-to-revoke | Incident readiness |
| Evidence export RTO | Audit readiness |
| Open IPI / egress findings | Honesty |

---

## Line for the board

Prompt injection is not solved. That is why we left the Filter Era. We mediate agency, contain privilege, and keep a ledger. That is governed velocity.
